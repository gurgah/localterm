Features

Multi-Tile Layout

Run up to 12 terminal tiles simultaneously. Expand any tile to fullscreen with one click.

Orchestrator Panel

Centralized permission management. Approve or deny requests from all terminals in one place.

Native Terminal

Full PTY support with xterm.js. Works with any shell - zsh, bash, fish, and more.

Cross-Platform

Available for macOS, Windows, and Linux. Built with Tauri for small bundle size.

Keyboard Shortcuts

Cmd+1-9 for tile selection, Cmd+T/W for new/close, and more.

Real-time Status

See which Claude sessions are working, waiting, or ready at a glance.
